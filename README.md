# RainFocus Summit UI

I built this single-page event setup guide from the RainFocus design using React and SCSS. I used the supplied icons and images and added a hamburger menu for smaller screens. You can click around the sidebar to try the selection states while staying on the setup guide.

## Open the app

Unzip the submission and open `build/index.html` in your browser. The compiled app and styles are included in that file, so you can open it without installing anything.

## Run it from source

With Node.js 22.12 or later installed, open a terminal in the project folder and run:

```sh
npm ci
npm run dev
```

Open the local URL printed in the terminal. If you make changes and want to regenerate the compiled page, run `npm run build`.
